## Traffic challenge boundary

Google's explicit `/sorry/index` page on `google.com` or `google.es`, accompanied by its observed unusual-traffic message, now ends a public run before another driver request, page analysis or final review. The original challenge picture remains saved and the journey stays partial. The explicit challenge takes priority over a generic access-denied title. Ordinary search results discussing unusual traffic, lookalike domains and pages without the explicit message do not earn this classification. This bounded recognition is not a general challenge detector or a way around a site restriction.
