# Remember an observed keyboard cycle

When a real target traversal returns to the same actual control, the next unchanged request must not replay that path merely because the model has made another decision or received another picture. For example, a requested consent button may remain behind a separate two-control offer dialog.

The engine remembers the actual target and cycle-member nodes, their observed dialog membership and relevant focusability state. Evidence names are bounded and scrubbed; no link address, input value or page HTML is added. A repeated refusal cites the first cycle record and its original actions. Each source is identified as a capture or a lightweight focus observation, preserving its original image/action chain. This records a robot limit, never a website keyboard-barrier finding.

The same target can be tried after relevant node, dialog, target-context or document changes, or when an explicit independent key moves actual focus outside the old cycle. An already focused target keeps the normal explicitly requested activation path and existing commitment guards. A new capture, unrelated text, changed wording or direction alone does not unlock another traversal. Unknown revalidation sends no input. The engine never dismisses a dialog or accepts consent automatically.

Memory is bounded by the existing driver limit and owns cloned handles until invalidation or cleanup. The shared dialog membership is read once per check. Runner Stop/final cleanup and page closure release the retained handles; pending reads cannot reopen closed memory. Ordinary explicit single-key actions and all existing input, time, model and money limits remain in force.

Controlled Chromium/WebKit and independent two-dialog proofs establish this behavior only. They do not prove arbitrary website navigation, real reader operation or a completed paid journey. A separate pre-existing commitment-label case found during the independent proof is retained separately; this proposal does not change the rule that blocks booking actions.
